# 设置与管理器预设

总设置预设位于「设置 → 常规 → 高级」底部，点击后打开独立悬浮窗。各管理器标题栏提供相同入口，共用命名保存、载入、更新、删除、JSON 导出与导入界面。导入只添加预设，点击「载入」才应用。

每类管理器拥有独立的预设列表，允许不同管理器使用同名预设。JSON 文件包含格式标识、版本、管理器类型、名称与数据。类型不匹配、无效配置、资源路径越界或超过大小限制的文件会被拒绝。

| 管理器 | 保存内容 |
| --- | --- |
| 总设置 | 全局偏好及当前自定义主题 CSS；保留当前项目独立设置和工具链 |
| 主题 | 主题选择、主题颜色参数及当前自定义主题 CSS |
| 快捷键 | 按键绑定与预览引用修饰键 |
| 块环境 | 环境配置，包括名称、视觉样式及行为 |
| 特殊命令 | 命令配置 |
| 拼写检查 | 检查模式、语言选择；词典安装和卸载仍使用原有入口 |
| LaTeX 工具链 | 引擎及检测/配置的工具链信息；不包含编译器程序 |
| 样式资源 | 当前为禁用占位；仅管理资源文件，暂无可保存的设置 |
| AI 技能 | 技能名称、内容与启用状态 |

块、命令和快捷键管理器按当前选定的全局/项目范围保存及载入。其他管理器使用全局范围。载入资源和技能时合并数据，不删除预设之外的条目；相同样式资源和主题内容会复用已有文件。

预设集中保存于用户数据目录的 `settings-presets.json`。`SettingsRepository` 复用串行队列与原子写入，偏好一次应用并向渲染进程发布一次更新。预设窗口支持 Esc、焦点限制及关闭后恢复焦点；操作期间禁止关闭。

`packages/contracts/src/settings-presets.ts` 定义类型、各管理器的配置边界和校验。新增管理器时扩展类型与配置键，并为文件类数据提供捕获/应用适配；无需重新实现预设 UI 和存储逻辑。
