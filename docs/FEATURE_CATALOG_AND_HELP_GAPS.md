# TeXWeave 功能总览与 Help 缺口

盘点日期：2026-10-12。当前源码版本以根目录 `package.json` 为准，为 **0.6.7**。版本号已更新，发行包仍未构建或发布。

本文基于当前桌面端与共享服务实现、自动化测试和 `docs/` 中维护的技术说明。Help 应介绍当前实际可用的功能；历史方案不能单独作为功能已经交付的证据，发生冲突时应优先核对当前实现和近期回归记录。`Update_tech_file/` 是已忽略的本地历史资料目录，新克隆仓库可能不包含它。

## 用户可见功能

### 首页与项目

- 创建空白项目或基于内置样式资源建立项目；空白项目可使用设置中的默认项目目录。也可以导入/登记已有项目文件夹。
- 项目列表显示名称、主 TeX 文件、项目大小、文件数量、位置和最近打开时间；可搜索、筛选、排序、分页，每页最多显示 10 个项目。
- 可收藏、置顶、选择和批量操作项目；单项目菜单提供打开、在文件资源管理器中显示、复制路径、修改显示名称、从列表移除和从磁盘删除等操作。
- “从列表移除”会询问如何处理 TeXWeave 保存的数据：全部保留、只保留正式版本，或全部删除。它与删除用户项目文件夹是不同操作。

### 工作区与文件

- 工作区以文件树、编辑器和 PDF 预览为中心，左侧工具栏可打开文件、搜索、文献库、AI、历史、关系和帮助面板。
- 文件树支持搜索/过滤、文件类型排序、新建和导入、重命名、复制路径、设置主文件、拖放整理等操作。文件夹展开状态和侧栏折叠状态会记忆。
- 多个文件可在编辑标签间切换；离开项目再进入时会恢复上次的源文件位置。未保存内容在离开、关闭窗口等路径上有保存提示。
- 可隐藏文件树中的编译产物与应用内部文件；这只控制文件树显示。编译输出另有过期产物清理逻辑。

### 源码编辑、联想与拼写

- Code 模式使用 Monaco 编辑 LaTeX、BibTeX 等文本文件，支持多文件标签、撤销/重做、查找/替换、格式化、自动配对、可选 minimap 和可配置快捷键。
- 项目级联想识别常用 LaTeX 命令/参数、环境、项目自定义命令和环境、标签与引用、BibTeX key，以及 `\input`、`\includegraphics`、文献数据库等项目路径。图片/文件建议从项目索引生成，并不要求资源已经被主文件引用。
- `\ref` 等引用可通过配置的修饰键跳到同一文档或当前项目可达的关联 TeX 文档；跨文档标签前缀按 `xr`/`xr-hyper` 的 `\externaldocument` 处理。前进/后退沿用快捷键管理器中的绑定。
- 拼写检查可关闭、自动检测或指定语言；支持个人词典、忽略单词、建议和源代码/Visual 编辑中的标记。英语词典随应用提供且不可卸载；其他词典可在管理器中选择安装/卸载。可用目录包含联网获取的 Hunspell 词典，以及哈萨克语词典；中文和日语使用独立的基础规则包。安装可选资源需要网络，已安装资源离线使用。

### Visual 结构化预览

- Visual 模式按源码范围呈现文章标题、章节、环境块、数学、列表、图片、表格、引用和受支持的特殊命令。源码仍是文档正文的唯一依据，Visual 是结构化阅读与局部编辑界面，不是完整 TeX 排版引擎。
- 结构块与内容块有不同操作能力。章节、定理、证明、列表等可包含子块；对父块执行复制、移动、禁用等整体操作时会作用于其内容和子块，特殊操作可按功能规则处理。
- 选中块后右键可在指针附近打开操作工具栏；Ctrl/Shift 可组合选择，方向键可按顺序移动选择，移动等连续操作会保留选择。折叠状态会按文件记忆；筛选命中或编辑等需要展示内容的操作可重新展开相关块。
- 章节等标题、文档标题、标签、图表的可选参数、caption 可按各自入口编辑对应源码。普通内容可在块内进入局部源码编辑；文档标题以特殊对象呈现，以便安全处理复杂标题宏。
- Outline 可折叠，并能从结构块及简单 LaTeX 命令生成导航条目。
- 块环境管理器配置匹配规则、启用状态、结构/内容类别、名称语言、标题字体、字号/粗细、外观和专项行为。名称可以按语言保存；显示可优先固定默认语言，缺项时按语言顺序回退。空的自定义语言值不作为翻译键查询。
- 特殊命令管理器将 `\appendix`、`\newpage` 等影响结构或分页的命令作为独立标记显示；命令定义可以配置颜色、视觉呈现和是否结束当前结构块。普通源代码空行本身不生成标记。
- `itemize`、`enumerate`、`description` 由可配置的内置 list handler 呈现，条目可识别/编辑，并按列表样式显示标记和序号。handler 由环境配置引用，名称本身不决定逻辑。
- 块与特殊命令的颜色可由基础色和主题参数自适应生成，也保留直接指定颜色的高级入口。预览支持增量解析、长文档虚拟化、源码映射和滚动锚点恢复。

### 搜索、筛选与导航

- Search 在项目文档中定位文本，可查看匹配上下文并进行替换；搜索和结构筛选是不同工具。
- Filter 按块类型、文档位置、文件和内容属性组合结果，可分别选择包含或排除条件，也可用总开关暂时停用筛选。搜索输入与筛选条件可配合使用。
- 关系范围可用于限定可见文档内容。预览中的标签、引用、章节导航和 PDF 同步定位共享源码位置信息。

### 图片与表格

- 图片可从项目、磁盘或剪贴板插入；剪贴板图片会复制到项目设定的图片资源目录。点击图片或图片槽位可替换路径，caption 与 label 可直接进入源码编辑。
- 图片属性支持宽高等参数和子图布局。可将普通 figure 调整为行列网格，拖动图片交换位置、填充空槽、移除单张图片或安全缩小布局；对无法安全解析的复杂源码会保留原文并要求改用源码编辑。
- 表格预览支持单元格编辑、插入/删除行列、合并/拆分单元格。表格被选中时显示浮动工具栏；扩大编辑器可以在独立窗口处理大表格，过宽内容可在单元格区域滚动。
- 这两类功能以常见 LaTeX 结构为目标。特殊宏、复杂嵌套和非标准写法应回到 Code 模式核查。

### 编译与 PDF

- 编译使用本机 `latexmk` 与所选 TeX 引擎（pdfLaTeX、XeLaTeX、LuaLaTeX 等），TeX Live/MiKTeX 等发行版需由用户安装或按实际安装流程配置。
- 编译主文件时生成主 PDF。切换到另一个 TeX 文件时，主文件仍参与编译，同时可编译并预览该 TeX 对应的 PDF。右侧 PDF 选择器可切换项目中的不同输出；设置可控制是否跟随当前 TeX 文件。
- 编译结果区提供 Problems、Output 和 Compile Log。结构化诊断能定位源文件/行号；原始日志仍可用于查看发行版或宏包的详细信息。AI 调用同一项目编译通道，其输出进入可供用户查看的 PDF 结果。
- PDF 预览支持缩放/适合页面或宽度、页面滚动位置记忆和 SyncTeX 源码到 PDF、PDF 到源码的定位。多栏 PDF 坐标按页内位置处理，不假设单栏顺序排版。
- 编译过程、临时 PDF、日志和辅助输出保存在项目 `.texweave/` 管理的构建位置；过期文档输出与日志有清理逻辑。编译失败、缺少 LaTeX 工具链和 SyncTeX 数据不可用是不同状态。

### 文献库与引用

- 全局 Reference Library 可导入和编辑 BibTeX/BibLaTeX 条目，检索、筛选、排序、收藏并给条目添加标签。
- 项目 Library 面板读取项目关联的 `.bib` 内容，并可在全局库与项目条目间查找、同步和插入引用 key。用户也可从 BibTeX 源码预览中检查条目。
- Code/Visual 中的 `\cite` 联想使用当前项目可用的所有文献 key；标签与引用支持源代码导航。跨文件 source navigation 按项目中实际的 `\input`/`\include`/`externaldocument` 连通关系解析，不会把不相关 TeX 文件中的同名 key 当作目标。

### 块关系

- Relations 是独立于 Outline 的工具，用于在合格的结构块之间建立有向逻辑依赖；“源块 → 目标块”表示目标依赖源块。支持前提、结果或双向范围、深度、焦点和文档筛选、路径查询、关系图及有效性诊断。
- 块层级与逻辑依赖是两种独立关系。系统拒绝无效端点、自环、重复边和有向循环；删除块会同步清理其边。关系保存在项目 `.texweave/structure.json`，并参与结构操作的撤销/重做。
- AI 可以查询关系并提出建立/删除/反转关系的建议；关系变更仍需要用户在专门的审批 UI 中明确批准。

### AI 对话与修改

- 提供 Copilot 与 Codex 对话入口，支持新建/切换/搜索/管理会话、Markdown 输出、LaTeX 数学渲染、推理与回答按时间顺序展示、耗时和消息复制。
- 输入支持文本、图片粘贴及文件附件；每个附件最多 20 MB，每个草稿最多 20 个附件、合计 50 MB。AI 可搜索当前项目文件和资源、读取关联源文件、查询块结构与引用；上下文使用项目文件与当前未保存编辑内容。附件暂存有独立容量限制和清理生命周期。
- 请求运行时可在不同项目或主页继续后台处理。活动请求期间发送的新消息进入队列，可选择排队等待、立即发送（中断当前工作）或移除。手动停止、失败会暂停队列；软件重启后未发送文本保留为暂停队列，临时附件需重新附加。
- 权限分为审查后应用、自动编辑和完全访问。Codex/Copilot 通过项目工作副本编辑；生成后以源码 diff 审查，可逐段或整体应用/拒绝。文本编辑采用行级差异；局部块修改可按精确范围提交。结构索引变化随源码解析更新，不应被误认为 AI 单独改写了整个结构文件。
- 消息可编辑并重新发送的入口仅用于最后一条用户消息。接受修改后使用工作台统一撤销/重做；完全访问模式允许外部命令或文件副作用，项目 diff/撤销不一定能恢复这些外部变化。
- AI 可调用编译接口并选择其他 TeX 编译目标。当前不代表所有真实模型、账号状态或工具链组合都经过在线端到端验证。

### 历史、恢复与导出

- History 区分正式版本、临时保存和自动快照。可创建/重命名正式版本、创建临时保存、查看差异、恢复整个项目或选定文件、提升快照为正式版本、删除条目及清理快照。
- 自动快照按进入项目后的计时与配置执行；自动保存是编辑器保存源文件的另一项设置。历史采用内容寻址和去重存储，可查看占用并优化存储。恢复前会创建安全点。
- 文件菜单提供三种导出：主 PDF、全部源码 ZIP、主文件依赖范围 ZIP。后两者保留目录结构并排除 TeXWeave 历史/元数据和构建产物；依赖归档尽可能收集递归输入、宏包、文献、图片和代码/数据文件。复杂动态 TeX 输入无法静态求解时，应重新编译以使用 `.fls` 记录，或导出全部源码。

### 设置、主题和资源

- 设置支持全局值和部分项目覆盖，分基础/高级两级；包含语言、自动保存、默认项目目录、文件树编译产物显示、侧栏布局、编辑器 minimap、PDF 跟随、历史保留、拼写、AI 权限、图片/表格行为等。自动保存默认关闭；开启后延迟默认 3 秒，间隔可设置。
- 快捷键管理器集中管理命令，包括搜索和左侧工具面板切换；引用跳转修饰键也由此配置。Help 应提供快捷键表和冲突说明。
- 内置主题包括 Light、Dark、Tech Light、Tech Dark、Pink Light；可导入 CSS 或主题目录。块/命令颜色通常基于基础色和主题参数自适应，用户也可以显式覆盖角色颜色。
- Block Environments 与 Preview Commands 管理器提供 GUI 和高级 XML 配置、开关、排序/筛选、语言名称、显示类型及预览。块/命令/快捷键等管理器可各自命名保存并载入设置预设，支持 JSON 导入/导出。Style Resources 管理器只管理 TeX 样式资源，不含可保存的设置，所以其预设入口当前禁用。
- 样式资源是给 LaTeX 文档使用的 `.sty` 等资源，与改变应用界面外观的 CSS Theme 是两套不同功能。
- 当前 UI 支持英语、简体中文、繁体中文、日语、韩语、法语和哈萨克语。语言选择下拉框显示语言本名；块和命令名称可按语言保存并按设定规则回退。

### CLI 与数据边界

- CLI 提供环境诊断、项目创建/登记/列表、文件树/读取/写入、主文件切换、编译、资源校验和资源搜索等脚本化入口；它复用共享服务，但不等于桌面 UI 的完整命令行镜像。
- 项目源码留在用户选定目录；项目结构、逻辑关系、构建和历史数据存于 `.texweave/`。项目登记、设置、全局文献、AI 会话及附件缓存等应用数据位于用户数据目录。应用本地优先，无内建云端项目同步。
- Electron renderer 通过白名单 IPC 请求主进程服务，文件系统路径在后端校验。AI 的完全访问是显式的高权限模式。

## 当前功能边界

- Visual 只实现安全识别的 LaTeX 子集和已注册的环境/命令 handler；它不会运行完整 TeX 宏展开，也无法保证预览外观与最终 PDF 一致。PDF 才是排版结果依据。
- 命令补全和项目索引采用轻量解析，常见声明、include 关系和静态路径可识别；不替代 TexLab/LSP 或 TeX 引擎，复杂宏、条件编译和任意宏包语义不一定可推断。
- 用户可配置环境、命令与内置 handler，但用户提供的 JavaScript/TypeScript 块插件运行、隔离、权限和卸载机制仍是未来能力。
- 拼写检查是单词/基础规则检查，不是语法、润色或论文事实核查。额外词典/规则资源的在线下载依赖网络；自动检测与可用词典范围受已安装资源限制。
- 主体应用与打包目标当前以 Windows 为主。发布前的干净机器安装、更新、卸载、原生依赖和数据保留验证仍需补齐。

## 工程验证范围

测试分为单元、项目服务集成、真实编译器、CLI 和 Electron 用户流程，并通过测试目录索引登记。Electron 场景已覆盖多 PDF、SyncTeX、长文档预览、搜索筛选、引用、图片/表格、AI 审阅、项目历史、快捷键/设置等关键路径；多数 AI 回归使用模拟服务，不消费账号额度。

这些检查说明对应的可重复场景已被自动化，不代表所有 TeX 发行版/宏包、真实 AI 服务状态、超长会话的长期内存曲线或最终安装包都已验证。0.6.7 发布评估报告中仍有本地化旧测试和译文质量问题，也没有完成最终包的干净 Windows 安装验证；发布门槛应以 [0.6.7 发布准备记录](RELEASE_READINESS_0.6.7.md) 的最新状态为准。

## 建议的 Help 信息架构

1. **开始使用**：安装/首次启动、创建或导入项目、设置 LaTeX 工具链。
2. **工作区**：文件树、Code/Visual/PDF、侧栏与分栏、Outline、位置恢复。
3. **编辑文档**：源码联想、搜索替换、快捷键、拼写检查、Visual 块和折叠。
4. **图表和表格**：插入/替换图片、剪贴板、子图、表格单元格与扩展编辑。
5. **编译与 PDF**：主文件、多 PDF、日志/错误、同步定位和常见工具链故障。
