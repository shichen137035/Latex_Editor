# 自动快照计时与去重

自动快照从当前项目打开时开始计时，按设置的 `intervalMinutes` 周期触发，默认 10 分钟。手动快照、删除前或恢复前安全点不影响周期。项目关闭时停止计时，重新打开重新开始；调整间隔仍以本次打开时间为锚点。后台窗口延迟后只检查一次，不补发多个快照；上一次检查尚未完成时不并发排队。

计时决定何时发起检查，内容去重决定是否新增历史记录。周期检查与项目关闭检查会与最近一条历史记录比较，包括正式版本和临时版本。内容相同不重复新增；手动快照仍允许用户明确创建。

常规去重忽略结构索引的派生范围、修订号、指纹和编号缓存；真实摘要、标签、关系、自定义块及未知元数据仍参与比较。此投影仅用于比较，历史内保存的结构文件始终完整。跳过的常规检查不写入未引用的结构对象和 manifest。

删除前快照继续保护真实删除，但相同完整内容不重复记录；撤销、重做已有文本操作不会再当作新的大规模删除。恢复操作始终保留独立的完整安全快照，方便用户撤回恢复。自动快照、删除保护和恢复保护的开关均在主进程再次校验。

回归测试：`tests/unit/snapshot-timer.test.ts` 和 `tests/integration/project-history.test.ts`。
