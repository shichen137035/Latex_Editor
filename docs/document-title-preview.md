# 文章标题预览与源码编辑

使用 `\maketitle` 的文档，标题在 Visual 中是一个独立源码对象。点击标题、作者或日期即可进入现有 Monaco 源码编辑器；支持应用、取消、Ctrl+S、退出前未保存提示，以及原有补全和公式预览。

解析器保留从首个标题元数据命令到 `\maketitle` 的连续原始范围，不把复杂作者、机构、脚注等命令拆成表单。若标题定义位于导言区，范围会保留中间的命令与 `\begin{document}`。应用仅替换该范围，区外内容逐字保留；编辑期间该范围被其他操作改动时，拒绝覆盖并提示。

标题不是普通结构块，不提供移动、复制、禁用等块操作。正文里的标题命令由此对象展示，不再重复渲染成正文段落。注释、转义命令和宏定义中的示例不触发标题识别；正文内的标题定义与导言区定义均可识别。

标题区域或其前方改变时重新解析以更新源码范围；标题后方的正文编辑继续走现有增量路径。结构解析修订号同步更新，已有索引会按当前规则重建。

回归命令：先执行 `npm run desktop:build`，再执行 `node apps/desktop/scripts/run-electron-check.mjs document-title`。单元测试位于 `tests/unit/document-title.test.ts`，界面测试覆盖复杂命令、精确保存、取消和 Ctrl+S 提交草稿。
