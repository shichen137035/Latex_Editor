# 应用版本与旧入口清理

根 `package.json` 的 `version` 是应用版本的唯一来源，目前为 `0.6.5`。`package-lock.json` 的根包版本与之保持一致；发行构建与包验证脚本已经使用该来源。

主进程的 `readAppInfo()` 同时供安装状态、AI 客户端初始化和 `app.info()` IPC 使用。首页挂载时调用此接口，显示 `v` 前缀及返回版本；退出项目返回首页时会重新读取。版本不经过翻译目录，也不依赖开发服务器启动时生成的常量。读取失败显示已有错误提示，避免用旧号或 Electron 自身版本兜底。

更新版本时修改根包版本和锁文件即可，随后重新启动开发应用或重新构建发行包。不同语言无需分别更新版本文案。Electron 界面测试从根包动态读取预期版本，并检查首次首页及退出项目后的首页。

本次删除的旧入口：

- 设置从旧 localStorage 键导入的迁移逻辑及遗留环境键常量；设置继续通过 IPC 和当前配置文件持久化。
- 无法进入的旧设置侧栏；帮助侧栏改为提供可用的快捷键管理和设置入口。
- 已经实现的 AI、关系图、搜索功能所遗留的不可用提示，旧在线样式库的空占位卡和相关翻译、样式。
- 结构服务和工作文档对 `.texweave/block-graph.json` 的回退；统一读取当前的 `.texweave/structure.json`。旧文件不会再被自动重新导入，文件本身不被删除。

文档内容为空、尚未编译 PDF、资源加载中的提示仍承担实际作用；用户要求保留的 Cloud workspace 开发中入口也继续保留。
