# 图片与子图布局

选中预览中的图片，在图片属性面板中选择布局，或填写行数和列数后应用。布局按「行 × 列」表示：`2 × 1` 为上下两张，`1 × 2` 为左右两张。行列数各支持 1–6。

## 剪贴板图片

在源码编辑区或预览中粘贴剪贴板图片，会在当前位置创建 figure 块，并将 PNG 副本保存到图片设置中的默认资源目录。选中预览块时的粘贴快捷键也会优先识别图片，然后才处理已有的块剪贴板数据。

“添加图片”对话框提供“从剪贴板粘贴”。在子图槽位打开该对话框时，仅替换所选槽位的路径，保留图片参数、说明与标签。没有图片时提示并保留对话框。

导入沿用本地图片的项目权限和重名处理，临时 PNG 文件在成功或失败后均会释放。

预览和属性面板中的缩略网格均支持拖动。拖到另一个位置时，两处的图片单元交换，包括各自的图片参数、子图说明和标签。空位置可通过现有图片选择器添加图片。缩小布局时，如果放不下已有内容，会提示并保留原始源码，不会自动删除图片。

## 源码与宏包

- 已有 `subfigure` 环境和 `\subfloat` 命令保持各自的语法。普通图片转换为子图时，保留外层浮动参数、说明和标签。
- 新建子图所需的宏包由图片编辑流程补充到所属文档前言中。子文件使用项目主文件的前言；具有独立 `\documentclass` 的文件使用自己的前言。
- 优先沿用已有 `subfig`；IEEEtran 使用 `subfig` 和 `caption=false`。其他文档默认采用 `subcaption`。发现冲突宏包时提示，不自动改写已有宏包。
- 复杂的嵌套包装、一个子图包含多张图片，或单元之间存在无法安全重排的代码时，布局操作会提示使用源码编辑。

宏包行为参考：[subfig](https://ctan.org/pkg/subfig)、[IEEEtran 作者文档](https://www.michaelshell.org/tex/ieeetran/)。

## 实现入口与验证

`figure/layout.ts` 负责布局解析与源码变换；`figure/packages.ts` 负责前言宏包；`workbench/figureEditing.ts` 在提交前检查源文件是否发生变化。预览和属性面板共享这些实现。

相关单元测试位于 `tests/unit/image-layout.test.ts`、`image-system.test.ts` 和 `image-replacement.test.ts`。桌面检查 `image-completion` 覆盖布局切换、拖动、空位置填充和缩小保护，并继续检查原有图片替换与资源联想。
