# Latex Block Relations

First discover and read the project relation-graph state. If the project has no explicit relations or legacy dependencies, skip relation lookups. Ordinary citations do not create a relation graph. An explicit request to create relations is an exception. For an existing graph, inspect only the relevant neighborhood and sources. Relation changes must use the existing proposal and explicit approval service, including full-access mode.
